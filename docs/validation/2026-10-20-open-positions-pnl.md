# Open positions and PnL

Dashboard versions 49–50 add a collapsed list of open broker positions and three distinctly scoped PnL metrics: whole-book floating, broker-reconciled Katarina DEMO floating, and realized Katarina DEMO results since enrolment. Row details include entry/current price, profit, swap, SL/TP and snapshot time. Open-state persists across refresh. USD/USC remain native units; no implicit cent conversion. Floating is profit plus swap, excluding unavailable open commission; realized results include the commission, swap and fee already recorded by the execution ledger. Historical PnL aggregates the entire closed ledger rather than the displayed 20-row page.

Position telemetry is captured by the existing read-only scanner. No order API is added. Ownership requires an OPEN outbox position ID plus matching symbol and side; unresolved submissions are not asserted as owned fills. Missing books/PnL remain unknown rather than zero. A future broker entry timestamp no longer discards an otherwise observed position: its entry time is explicitly unavailable instead of guessing an offset. Position snapshot time is validated independently from the parent report's earlier observation time.

Legacy intents did not persist risk currency. Their PnL is exposed only when a fresh DEMO account snapshot's private binding hash matches the persistent enrolment ledger. The hash, account IDs, tickets, volume, balances, equity and credentials are excluded from the public feed.
